# crisis-response-ai
🚨 Rapid Crisis Response System (RCRS)

An AI-powered emergency response web application designed to provide instant assistance during critical situations.
Built using Google Gemini AI, this system helps users quickly send alerts, access nearby help, and receive real-time safety guidance.

🌟 Key Features

- 🚨 One-tap SOS Activation
  Instantly trigger an emergency alert

- 📍 Live Location Tracking
  Automatically detects and shares user location

- 🤖 AI-Generated Emergency Messages
  Smart SOS messages generated using Gemini AI

- 🧠 AI Safety Guidance
  Get instant instructions during emergencies

- 📞 Emergency Contacts Management
  Add, remove, and notify trusted contacts

- 🏥 Nearby Help Detection
  Displays hospitals and police stations (simulated)

- ⚠️ Accident Detection Simulation
  Auto-triggers SOS for testing scenarios

---

🧠 AI Integration

This project integrates Google Gemini API via Google Apps Script as a secure backend.

Why this approach?

- 🔒 Protects API key from exposure
- ⚡ Enables fast AI responses
- 🔗 Seamless frontend-backend communication

AI is used for:

- Generating emergency SOS messages
- Providing real-time safety guidance

---

🛠 Tech Stack

- Frontend: HTML, CSS, JavaScript
- Maps: Leaflet.js
- Backend: Google Apps Script
- AI: Google Gemini API

---

🚀 How It Works

1. User clicks the SOS button
2. System fetches the live location
3. AI generates a context-aware emergency message
4. Nearby help locations are displayed
5. Alert is shared with emergency contacts

---

📂 Project Structure

index.html → Main UI + frontend logic
